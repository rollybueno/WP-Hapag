A Filipino-inspired WordPress block theme for recipes, food creators, and small shops.

== Description ==

Hapag takes its name from the Filipino word for the dining table — a place for food, sharing, and gathering.

The theme is built for Full Site Editing with a theme.json-first design system: named colors, fluid type, spacing presets, and native WordPress blocks. Custom CSS is reserved for compositions theme.json cannot express.

== Installation ==

1. Clone or copy this theme into wp-content/themes/hapag
2. Activate Hapag from Appearance → Themes
3. Edit the header, footer, and templates from Appearance → Editor

The GitHub repository is named wp-hapag. The WordPress theme directory must remain hapag.
